# 📄 Ali’s Résumé Website

A clean, **fully responsive** résumé website built using **ReactJS** and **Tailwind CSS**. The entire application is bundled into a single HTML file (`index.html`) for extremely simple hosting, as currrently hosted in github.

This project showcases my professional experience, skills, and contact information in a modern, lightweight, and easily deployable format.

---

## 🚀 Live Demo

👉 [https://danishdynamic.github.io/myaliweb.github.io/]

---

## ✨ Features

* **Fully Responsive UI:** Adapts seamlessly to all screen sizes (desktop, tablet, and mobile).
* **Modern Design:** Sleek, minimalist aesthetics powered by **Tailwind CSS**.
* **Single-File Build:** Built using React components but optimized and exported as a **single HTML file** (`resume.html`).
* **Fast and Lightweight:** Minimal footprint for near-instant loading.
* **Easy to Modify:** Simple structure for quick updates and redeployment.

---

## 🛠️ Tech Stack

* **Frontend Framework:** ReactJS
* **Styling:** Tailwind CSS (utility-first approach)
* **Final Output:** HTML (single file)

---

## 📁 Project Structure

The single-file approach makes the repository very clean:

- **project-root/**
  - index.html
  - README.md


> **Note:** The development source code (e.g., React components, assets, `package.json`) is not included in this repository, only the final production build.

## ▶️ Usage

To view the site locally, no build tools or servers are required!

1.  **Download or clone the repository:**
    ```bash
    git clone [https://github.com/danishdynamic/myaliweb.git]
    ```
2.  **Open `resume.html`** in any modern web browser.

---

## 🌐 Deployment

Since this is a single, self-contained HTML file, deployment is trivial on any static hosting platform:

1.  **Upload `index.html`** as your site's root file (e.g., `index.html` if the host requires it).
2.  **Done!**

Recommended services:

* GitHub Pages
* Netlify
* Vercel
* Any static hosting service
